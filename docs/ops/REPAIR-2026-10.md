## Behavior repaired

- **Profiles:** authenticated people can edit their own name, username, email, patronymic and
  position. Duplicate usernames conflict; profile editing cannot grant roles. Email is returned by
  the self-profile endpoint rather than added to the public directory projection.
- **Projects:** edit title, description, dates, status, color and participants; heads can change
  ownership. Owners remain participants and membership validation rejects departed members.
  Conversion creates a group project around the original card, preserving its comments, checklist
  and files. Project cards are fetched by immutable project ID, including pagination.
- **Task deletion:** team views hide the retained row. The deleting actor has a 30-second undo
  window; the UI keeps the undo toast for 20 seconds. Superadmin audit records retain the title,
  actor and deletion time. Child endpoints, dependency edges and automation history respect deletion.
  Archive/restore remains a separate operation. Permanent purge is not introduced.
- **Attachments:** add actual files alongside links. Finalization publishes the exact scanned bytes
  under a different object key, preventing a replayed upload URL from replacing a clean file.
  Downloads recheck card/tenant access and use attachment disposition. Soft deletion retains bytes
  and metadata with actor-bound undo. Scanner outages leave files private and offer retry.
- **Integrations and health:** Telegram setup/connectivity and AI provider behavior have explicit
  settings/status paths. Storage health checks the configured driver rather than an unrelated
  optional variable. Backup health consumes a read-only success marker, not database dumps.
- **Usability:** head/member starting paths, a clearer task composer, editable projects/profile,
  visible project-task save controls, clear disabled-feature states for Workload/Goals, and accessibility fixes. Quick help is a fixed knowledge-base
  entry with nine answers in three searchable groups, each linking to the relevant screen.
- **Session resilience:** pending/failed `/me` cannot mount private mutation hooks. A failed session
  query offers retry; a signed-out private visit opens login. Logout cancels reads and clears private
  query/mutation cache. Public routes, unknown-route handling and test-only forced states remain.
- **Security/performance:** explicit JSON response media types; independent scanner, field,
  automation and metrics work uses bounded concurrency. Ordered writes and cursor pagination retain
  precise local explanations. Automation run logs now refresh through outbox/realtime rather than
  a fixed polling timer.
