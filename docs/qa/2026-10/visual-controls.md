## Harness and meaningful scenarios

`apps/web/test/e2e/visual-controls.config.ts` runs visual-controls, people-controls, badge-contrast, native-controls, card-readability and avatar-readability. `nested-capabilities.config.ts` covers large People, gallery, conversion/edit, milestones/progress/delete, structure/export and short-height dialogs. Dedicated database: `devon_flow_e2e_visual`; API 48911/web 48912; loopback PostgreSQL 55432. Shared safety guard rejects unrelated databases and external DNS/network. Results use independent `artifacts/qa/2026-10/results/visual-controls` and `visual-capabilities`. No retries were used to hide failures.

Badge/native fixture is browser-mounted React using actual `@devon/ui` components through local Vite. It is not imported by the application or exposed as a production route. Badge contrast composites translucent surfaces over actual ancestors. Label contrast samples foreground/background over the same parent surface; after full opacity, it measures the actual rendered colour pair.

Milestones: title-click completion, independent read/reload, keyboard pencil/tooltip/focus return, controlled local 503, frozen pending fields, retained draft, unchanged server record, retry/reload. Cards: separated selection and movement, title edit/persistence, repeated widening/narrowing, truthful window error recording, group-cancellation persistence. Labels: correct accessible name, readable unselected state, normal toggling and independent persistence, failed creation with retained draft, successful Enter retry, reader sees applied tags without edit controls. People: real horizontal keyboard scrolling, target geometry, actual physical resize, all arrow keys, reload, End and Home. Native theme changes retain date/select values.

## Evidence quality corrections

Early startup failures from empty optional Telegram variables and a 0.0.0.0 listen/DNS guard performed no browser tests or integration calls. Parent fixed absent optional values; local_services added loopback API_HOST. An older WebKit trace failed during another runner's nested-output cleanup; output directories are now independent.

A nominal 24px target measured 23.999969px; 0.01px geometry tolerance covers engine rounding. Dialog captures wait for opacity 1; rows wait for entrance opacity 1. Native fixture captures initially occurred during Input colour/background transitions and were rejected as final pixel evidence; `settleCapture` now waits for finite animations. No error was suppressed to make these tests pass.

First 200% attempt changed html font-size, which did not enlarge fixed-px typography. It was discarded. The correct test doubles actual typography and line-height tokens while retaining spacing/icons. This verifies text enlargement, not browser-UI zoom. Initial host-side React fixture failed Playwright JSX serialization and was replaced with actual browser React. ResizeObserver error recording uses the real window error event because browsers need not emit Playwright pageerror for that event.

Nested fixture corrections: invite protection allows ten joins in ten minutes; the disposable local65-person fixture rotates its own key after every eight members instead of weakening the limiter. Initial profile seed used the wrong route; maintained API profile route corrected it. An exact native Status label lookup failed because native option text contributes to the label; the regression now locates the actual combobox by its maintained Status prefix. The Avatar fixture's Tailwind-only overlay class was not emitted from test-only source; an explicit fixture z-index ensures clean component evidence. These fixture failures are not counted as product defects.

One expanded run mistakenly used parent's reserved 48931/48932 ports. Its verified owned session was stopped, listeners were confirmed released, and its unfinished results were not counted as a pass. All subsequent runs use 48911/48912. Independent database names/roles and output directories remain enforced. No unrelated process was killed.

## Rationale and remaining scope

Keep familiar workflows and compact visuals. Give interactive targets and text sufficient contrast, group related content, reserve real flow height, and retain complete names/tooltips for terse controls. Distinguish selection without making available actions appear disabled. Consequential Delete remains distinct from Save with undo/focus paths preserved.
