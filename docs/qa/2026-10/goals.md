# Department goals: persisted workflow and recovery audit

Goals are department-head management objects. All four metrics are recomputed from real card data on read; users do not manually edit progress. Member access stays refused at the UI and API. This stream uses only synthetic local records, a dedicated `devon_flow_e2e_goals` database and API48961/web48962. External browser requests are refused. No production, deployment, push, AI/Telegram calls or recording occurred.
