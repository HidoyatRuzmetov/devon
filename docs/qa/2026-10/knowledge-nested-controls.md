## Reproduction

Set `FLOW_DB_NAME=devon_flow_e2e_knowledge_nested`, `FLOW_API_PORT=48921`, `FLOW_WEB_PORT=48922`, `FLOW_SEED_DEMO=1` and a fresh `QA_RUN_ID`. Run from the repo root with the supported pnpm launcher:

```powershell
pnpm --filter @devon/web exec playwright test --config test/e2e/knowledge-controls-qa.config.ts knowledge-controls.qa.spec.ts
pnpm --filter @devon/web exec playwright test --config test/e2e/knowledge-controls-qa.config.ts knowledge-visual.qa.spec.ts --project chromium
pnpm --filter @devon/web exec vitest run --config test/vitest.config.ts test/unit/onboarding-templates.test.tsx test/unit/page-suggestions.test.ts test/unit/faq.test.tsx test/unit/callout-toggle.test.ts
pnpm --filter @devon/web typecheck
```

`tools/qa/knowledge-contact-sheets.py <absolute-run-directory>` builds visual comparison sheets from exact discovered capture manifests. `tools/qa/knowledge-functional-sheets.py <absolute-run-directory>` builds functional comparisons and unmodified detail regions. Neither script marks images reviewed. The final JSON overlay has35 stable source signatures and additional runtime-generated controls for parent census reconciliation.
