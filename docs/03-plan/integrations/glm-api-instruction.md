# LLM API — инструкция для пользователя

## Что это

OpenAI-совместимый API с большой языковой моделью GLM на GPU-кластере INHA.
Работает с любой библиотекой или инструментом, поддерживающим OpenAI API.

- **Базовый URL:** `https://api-llm.gpu.uz/v1`
- **Авторизация:** заголовок `Authorization: Bearer <ВАШ_КЛЮЧ>`

- **Ключ:**

## Модель

| Модель | Что умеет | Цена (за 1 млн токенов) |
|---|---|---|
| `glm-5.2` | Флагманская модель для сложных задач, программирования, агентов и tool-calling. Всегда рассуждает перед ответом | 19 500 UZS |

Контекст модели — **256 000 токенов** (вход + выход). Входные и выходные
токены тарифицируются по одной цене.

## Быстрый старт (curl)

```bash
curl -s https://api-llm.gpu.uz/v1/chat/completions \
  -H "Authorization: Bearer ВАШ_КЛЮЧ" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "glm-5.2",
    "messages": [{"role": "user", "content": "Привет! Что ты умеешь?"}],
    "max_tokens": 2048
  }'
```

## Python (официальный openai SDK)

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://api-llm.gpu.uz/v1",
    api_key="<ВАШ_КЛЮЧ>",  # placeholder — paste your own key, never commit it
)

resp = client.chat.completions.create(
    model="glm-5.2",
    messages=[{"role": "user", "content": "Объясни, что такое REST API"}],
    max_tokens=2048,
)
print(resp.choices[0].message.content)
```

Стриминг — как в OpenAI: укажите `stream=True`, затем обрабатывайте ответ
по частям.

## Три вещи, которые надо знать

1. **`glm-5.2` всегда рассуждает** перед ответом и тратит на это часть
   `max_tokens` (обычно 200–500). Ставьте `max_tokens` с запасом — не менее
   1024, а для сложных задач рекомендуется 2048 и больше. Если получили пустой
   `content` и `finish_reason: "length"`, увеличьте `max_tokens`. Текст
   рассуждений приходит в отдельном поле `message.reasoning_content`.

2. **Tool-calling (functions) поддерживается** в стандартном формате OpenAI.
   Передайте инструменты в параметре `tools`, а способ их выбора — в
   `tool_choice`. Вызовы инструментов вернутся в `message.tool_calls`.

3. **Размер контекста ограничен 256 000 токенов.** В этот лимит входят весь
   текст запроса, история диалога, описания инструментов, рассуждения модели и
   итоговый ответ. Для длинных диалогов сокращайте историю и задавайте
   `max_tokens` с учётом оставшегося контекста.
